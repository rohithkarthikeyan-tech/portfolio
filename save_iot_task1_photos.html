🔒 How to Make the ESP32 URL Secure with HTTPS

By default, local ESP32 IP servers use unencrypted HTTP (Port 80). To make the URL secure like HTTPS (Port 443 with SSL/TLS):

  • Use SSL/TLS Library: Include WiFiClientSecure.h or HTTPSServer.hpp in Arduino IDE.
  • Load SSL Certificate: Generate a self-signed SSL X.509 certificate & RSA private key in PEM format.
  • Listen on Port 443: Initialize the ESP32 web server on Port 443 instead of Port 80.
  • Secure URL format: Access via https://172.20.103.235/ instead of http://172.20.103.235/.

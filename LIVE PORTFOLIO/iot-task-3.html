1. Overview

Experiment 03 focuses on acquiring real-time physical environmental measurements using the DHT11 capacitive humidity and thermistor temperature sensor. The ESP32 parses custom single-bus timing protocols to extract temperature (°C) and relative humidity (%) readings, which are subsequently published over MQTT to cloud dashboards for live telemetry visualization and threshold monitoring.

2. Core Concepts

Concept Function / Role
Capacitive Sensing Measures atmospheric relative humidity via dielectric polymer film.
NTC Thermistor Measures ambient temperature through negative temperature coefficient resistor.
Single-Bus Protocol Custom 40-bit serial packet communication over a single GPIO pin.

6. Implementation Code

esp32_dht11_mqtt.ino 
// Task 03: ESP32 DHT11 Sensor & Cloud Telemetry
#include <WiFi.h>
#include <DHT.h>

#define DHTPIN 4
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(115200);
  dht.begin();
  Serial.println("=== DHT11 Environmental Telemetry Active ===");
}

void loop() {
  delay(2000); // 2 second sampling period

  float h = dht.readHumidity();
  float t = dht.readTemperature();

  if (isnan(h) || isnan(t)) {
    Serial.println("Failed to read from DHT sensor!");
    return;
  }

  Serial.print("Humidity: ");
  Serial.print(h);
  Serial.print(" % | Temp: ");
  Serial.print(t);
  Serial.println(" °C");
}

9. Challenges & Fixes

Challenge

Sensor returning NaN (Not a Number) readings on execution loop.

Fix / Solution

Added a 10kΩ pull-up resistor between the VCC line and Data signal pin, and enforced a minimum 2.0s loop delay.
